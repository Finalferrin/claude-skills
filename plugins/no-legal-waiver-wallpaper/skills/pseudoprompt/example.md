# Worked example

The paragraph that asked for this skill, converted by the skill.

## Paragraph

> so read my confluence pages, not summaries or titles on anything to do with writing prompts
> in pseudo code. and also look through my research in google drive and in workshop in d. I
> want to make a skill that takes a normal prompt like this one, and converts to pseudo code
> for larger asks, like if im design ing something i lay it out all out in a hugen paragraph,
> the skill turns that to pseudo code and writes a new prompt and displays as a copy paste
> blocks.

## The block

```
PURPOSE
    a skill that takes a normal prompt, converts it to pseudo code, writes a new prompt
    and displays it as copy paste blocks

SCOPE
    IN   my confluence pages on anything to do with writing prompts in pseudo code
    IN   my research in google drive
    IN   my research in workshop in d
    IN   the skill, for larger asks, like a design laid out in one huge paragraph

VOCABULARY
    pseudo code
    skill
    normal prompt
    larger asks
    copy paste blocks
    workshop in d

EXCLUSIONS
    NEVER read summaries in place of the confluence pages
    NEVER read titles in place of the confluence pages

STEPS
    FIRST  read my confluence pages on anything to do with writing prompts in pseudo code
    THEN   look through my research in google drive
    THEN   look through my research in workshop in d
    THEN   make the skill
    IF the ask is a larger ask:
        the skill turns it to pseudo code
        the skill writes a new prompt
        the skill displays the new prompt as copy paste blocks

OUTPUT
    the skill
```

## On screen, under the block

- Where is "workshop in d"? Kept as your words. Give the receiving agent the path if it
  should not look for it.
- Where should the skill be saved, and in what form? The paragraph says only "the skill".
- "copy paste blocks" is plural. Kept plural. Say if you meant one block per prompt.
- "not summaries or titles" came right after "confluence pages", so the NEVER lines cover
  Confluence only. Drive and workshop say "look through", kept as written.
- Typo readings: "design ing" as "designing", "hugen" as "huge". "pseudo code" is spelled as
  you spelled it.

## What is not in the block, and why

- No section names, keywords or method from the skill itself. The block describes the
  author's task, not how it was converted.
- No testing step, no "deliverable criteria", no "synthesise findings", no side-by-side
  view. Three agents converting this paragraph without the skill added each of those. None
  was said.
- No path for "workshop in d". A reasonable default is still an invention; the question on
  screen carries it instead. One agent wrote D:\Codex into the block "per your memory". Memory
  is not the paragraph.
- No rules from the author's CLAUDE.md or memory. The receiving agent has its own copy.
